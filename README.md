# Семечко

Небольшая браузерная игра на 12–15 минут.

**Играть:** https://k5302964-sketch.github.io/semechko/

Вся игра — один файл [`index.html`](index.html). Его можно скачать и открыть двойным щелчком, интернет не нужен.

## Управление

- ← → или A D — идти
- пробел, ↑ или W — прыжок (держать — выше)
- на телефоне — кнопки внизу экрана, телефон держать горизонтально

Проиграть нельзя: из ямы или воды семечко мягко возвращается на безопасное место.
